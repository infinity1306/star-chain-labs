# SPEC.md: Star Chain Labs Digital Engineering Studio Website

## 1. Objective
Build a complete, production-ready, agency-grade website for **STAR CHAIN LABS** based on the Figma design language reference (node-id=3-7).
The website serves as the primary digital presence for Star Chain Labs, positioning the company as an elite digital engineering studio and premium technology consultancy.

## 2. Brand & Visual Identity
- **Palette**:
  - Background / Linen: `#FDFBF7`
  - Dark Mineral Brown: `#1C1613`
  - Muted Beige: `#F4F0EA`
  - Border Light: `#EAE6E1`
  - Border Dark: `#2D2421`
  - Olive Accent: `#4A5840`
  - Brass / Gold Accent: `#C5A059`
  - Secondary Sage: `#8A9A86`
- **Typography**:
  - Primary Display Serif: `Cormorant Garamond` (Weights 400, 500, 600, 700)
  - UI / Body: `Instrument Sans` (Weights 400, 500, 600, 700)
  - Hero Heading: ~64px desktop, line-height 1.05
  - Section Headings: ~48px serif
  - Card Headings: ~28px serif
  - Body: 14–18px Instrument Sans
  - Metadata / Badges: 11–13px uppercase, letter-spaced
- **Layout & Spacing**:
  - Desktop: 1440px max-width, 80px page margins
  - Tablet: 768px, 40px margins
  - Mobile: 390–402px, 24px margins
  - Subtle corner radii: 4px, 6px, 8px.
  - Crisp 1px borders.

## 3. Scope of Sections
1. **Header / Navbar**: Brand mark SVG, persistent navigation links, outlined brass/mineral CTA, accessible mobile drawer.
2. **Hero Section**: Mineral dark (#1C1613) with two-column split: editorial statement + interactive HTML5 constellation canvas with telemetry readouts.
3. **Trust & Credibility Strip**: Understated typographic tickers.
4. **Services**: 6 comprehensive engineering service cards with custom icons and capability tags.
5. **Capabilities / System Architecture Blueprint**: 8-tier interactive architectural diagram ("FROM IDEA TO OPERATING SYSTEM").
6. **Featured Work**: Editorial case studies with Challenge, Solution, Architecture & Stack, and Measurable Outcomes.
7. **Why Star Chain Labs**: Split editorial layout + 3 core pillars + interactive target industries matrix.
8. **Process**: 6-step sequential pipeline with brass metadata and engineering criteria.
9. **Technology Stack**: Typographic categorized matrix (Frontend, Backend, Database, AI, Infrastructure, Security).
10. **Project Inquiry**: Interactive form with validation, service selection, and technical inquiry lifecycle diagram.
11. **Footer**: Mineral dark background, brand identity, operational status indicator, full sitemap, back-to-top button.
12. **SEO & Accessibility**: OpenGraph, Schema.org JSON-LD, semantic markup, WCAG 2.2 AA compliant focus states and `prefers-reduced-motion`.

## 4. Technical Constraints
- Framework: Vite + semantic HTML5 + Vanilla CSS (Variables) + Modular JavaScript.
- Zero bulky external UI dependencies.
- 100% responsive without horizontal scrolling.
- Fast initial paint and smooth 60fps micro-motion.
